# 🇩🇪 Deutsch Weg — немецкий с нуля до B2

Интерактивный курс немецкого языка для русскоговорящих: **41 урок** (A1 → A2 → B1 → B2), **600+ слов**, **330+ фраз**, **240+ упражнений на грамматику**, **41 интерактивный диалог** — плюс ИИ-собеседник на базе **Grok (xAI)**.

## Что внутри

**Каждый урок** — это не лекция, а цепочка коротких интерактивов (25–40 шагов):

| | |
|---|---|
| 📘 Мини-грамматика | 3–5 пунктов + таблица, без воды |
| 🃏 Карточки слов | с озвучкой, цветом рода (der/die/das) и проверкой произношения |
| 🔗 Пары, выбор ответа, артикли | закрепление слов сразу после знакомства |
| 🧩 Сборка предложений | из слов-плиток, как пазл |
| ✏️ Пропуски | грамматика урока в контексте |
| 🎧 Аудирование | услышать фразу → выбрать перевод / записать |
| 🎙️ Произношение | говорите в микрофон, приложение подсвечивает слова, которые не распознались |
| 🎭 Интерактивный диалог | собеседник говорит, вы выбираете или **произносите** свою реплику |

Ошибки возвращаются в конец урока, за серию правильных ответов — 🔥 комбо.

**ИИ-функции (Grok):**
- 💬 **Ролевые разговоры** — у каждого урока свой сценарий (кафе, врач, собеседование, дебаты B2…) + свободные сценарии. Голосом или текстом. ИИ отвечает на вашем уровне, **исправляет ошибки** прямо в чате, даёт **подсказки** что ответить, а в конце ставит **оценку** с разбором.
- 🤖 **«Почему?»** — объяснение любой вашей ошибки в упражнении.
- ✨ **Новые задания** — бесконечная генерация упражнений по теме урока.
- ✍️ **Письмо с проверкой** — задание, оценка, разбор ошибок и «как сказал бы носитель».
- 📖 **Мини-истории** — интересные тексты на вашем уровне с озвучкой, переводом по клику и вопросами.
- 👩‍🏫 **Спросить учителя** — любые вопросы о грамматике на русском.

**Плюс:**
- 🔁 **Интервальное повторение** (система Лейтнера: 8 ч → 1 д → 3 д → 7 д → 14 д → 30 д), «трудные слова», журнал ошибок.
- 🎮 **Игры**: Artikel-Blitz, Wort-Sprint, Zahlen hören (числа на слух), Satz-Puzzle.
- ⭐ XP, 🔥 серия дней, 🎯 цель дня, звёзды за уроки, тепловая карта активности.
- Экспорт/импорт прогресса, тёмная/светлая тема (по системе), работает на телефоне (PWA).

## Запуск

Нужен Node.js 18+.

```bash
npm install
cp .env.example .env        # и впишите XAI_API_KEY=xai-...
npm run dev                 # разработка: http://localhost:5173
```

Продакшен (сборка + мини-сервер без зависимостей, который проксирует запросы к Grok, чтобы ключ не попадал в браузер):

```bash
npm run build
npm start                   # http://localhost:5173 (порт меняется через PORT в .env)
```

### Ключ Grok

1. Получите ключ на https://console.x.ai
2. Либо положите его в `.env` (`XAI_API_KEY=...`) — **рекомендуется**,
   либо введите в приложении: **Профиль → Настройки → ИИ** (хранится только в вашем браузере).
3. Модель по умолчанию — `grok-4-fast-non-reasoning` (быстрая и недорогая); меняется в настройках.
4. Кнопка «Проверить подключение» в настройках покажет, всё ли работает.

Если вы размещаете приложение как статический сайт (без `server.mjs`), выберите в настройках «Напрямую к api.x.ai» и введите ключ.

### Голос

Озвучка и распознавание речи используют встроенные возможности браузера (Web Speech API).
**Лучше всего — Chrome или Edge** (на компьютере и Android). В Safari/Firefox распознавание может быть недоступно — тогда задания на произношение можно пройти с самопроверкой. Немецкий голос выбирается в настройках.

## Структура

```
src/
  data/a1.ts … b2.ts     — контент курса (компактный формат, легко дополнять)
  data/index.ts          — парсер контента
  lib/exercises.ts       — генерация упражнений из урока
  lib/grok.ts            — клиент Grok API
  lib/speech.ts          — озвучка и распознавание речи
  lib/storage.ts         — прогресс, настройки, интервальное повторение
  components/            — упражнения, плеер урока, ИИ-разделы, игры
server.mjs               — продакшен-сервер + прокси /api/chat
scripts/check-content.mjs — проверка корректности контента (npm run check)
```

### Как добавить урок

Добавьте объект в `src/data/a1.ts` (или другой уровень):

```ts
words: `der Tisch, -e|стол
gehen|идти`,
phrases: `Ich heiße Anna.|Меня зовут Анна.`,
gaps: `Ich {heiße} Anna.|Меня зовут Анна.|heiße,heißt,heißen`,
dialog: `A:Wie heißt du?|Как тебя зовут?
B:Ich heiße Anna.|Меня зовут Анна.`,   // A — собеседник, B — ученик
```

Упражнения (карточки, пары, сборка, аудирование, произношение, диалог) создаются автоматически. Запустите `npm run check`, чтобы проверить контент.

## Версия-артефакт для claude.ai

`npm run build:artifact` собирает всё приложение в один файл `artifact/deutsch-weg.html`, который публикуется как артефакт claude.ai. В этом режиме:
- ИИ-преподаватель — встроенный Claude (ключ не нужен);
- прогресс хранится в браузере и синхронизируется с аккаунтом Claude (одинаковый на телефоне и компьютере);
- голосовой ввод — через диктовку Claude (Chrome/Edge и приложение Claude на компьютере);
- озвучка — голосом браузера, а если немецкого голоса нет — голосом Claude.
